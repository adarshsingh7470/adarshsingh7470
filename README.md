## 🤝 Open Source — zenml-io/zenml

Recently started contributing to ZenML, an open source MLOps platform.
Here's what I've worked on so far:

- 🐛 **[Bug Fix]** Found and fixed 3 bugs in AWS CloudFormation template —
  ECR tag misconfiguration (`!Sub` vs `!Ref`), CodeBuild `PrivilegedMode`
  breaking Docker-in-Docker builds, deprecated Lambda `python3.8` runtime
- 🔒 **[Feature]** Proposed S3 server-side encryption + ECR image
  scanning for production security hardening
- 🔧 **[Bug Report]** Identified 3 breaking issues in
  `aws-artifact-store-setup.sh` — `us-east-1` region crash,
  missing `jq` dependency check, overly permissive `s3:*` IAM policy
- ⚙️ **[Security]** Replacing third-party GitHub Actions
  (`peter-evans/find-comment`) with native `gh` CLI to eliminate
  supply chain attack risk — [issue #4664](https://github.com/zenml-io/zenml/issues/4664)
